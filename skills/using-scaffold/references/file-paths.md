# File Path Quick-Reference

## Spec Templates

| Template | Purpose |
|---|---|
| `specs/template/proposal.md` | + brainstorming needs clarification |
| `specs/template/design.md` | Technical design |
| `specs/template/tasks.md` | + writing-plans structure |
| `specs/template/verdict.md` | + double-check gate |
| `specs/template/change-proposal.md` | Lightweight change requests |
| `specs/template/context.md` | Context documentation |

Copy template → `specs/active/YYYY-MM-DD-<slug>/<file>.md`, fill in, follow the flow.
